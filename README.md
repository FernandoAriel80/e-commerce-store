# 🛍️ Proyecto E-commerce 

Este proyecto es una **aplicación web desarrollada en React** que simula una **tienda online**, permitiendo explorar productos, ver sus detalles y agregarlos a un carrito de compras.

## 🎯 Objetivo del proyecto

El propósito de este proyecto es aplicar los conocimientos aprendidos en el **curso de React de Talento Tech**, desarrollando una aplicación práctica con funcionalidades típicas de un e-commerce moderno.

## ⚙️ Tecnologías utilizadas

- **React.js** — para la construcción de la interfaz de usuario.  
- **Vite** — como entorno de desarrollo rápido.  
- **HTML / CSS / JavaScript (ES6)**  
- **Mock API** — como fuente de datos para simular productos reales.  
- **Fetch API** — para realizar las solicitudes HTTP.  

## 🧩 Descripción de la API utilizada

Para obtener los productos de la tienda se utiliza la API pública **[Fetch API](https://mockapi.io/)**.
